# 🤝 Contributing to Azure DevOps GitFlow Extension

We love your input! Whether it's fixing a bug, improving docs, or adding new GitFlow functionality — your help makes this better for everyone.

---

## 🧱 How to Contribute

1. **Fork** the repository
2. **Clone** your fork:
   ```bash
   git clone https://github.com/<your-username>/Azure-DevOps-Gitflow-extension.git
  ```
